# Smart Cash Control v2.1 - Pro Edition 🚀

Versión avanzada con control de efectivo en cajón y reserva en caja fuerte.

## 🆕 Novedades en la v2.1
* **Campo Caja Fuerte:** Añadido un campo dedicado en el desglose de efectivo que suma el importe de la caja fuerte al total contado para obtener el **Total Real Caja**.
* **Integración Contable:** El nuevo importe se sincroniza automáticamente con el módulo de conciliación TPV.
* **Auditoría Extendida:** El archivo JSON ahora incluye también el valor almacenado en la caja fuerte.

## 🛠️ Funcionalidades Principales
1. **Resumen Cierre:** Control de flujo neto (Fondo Ayer + Efectivo - Gastos - Sobre).
2. **Desglose de Efectivo:** Conteo pieza a pieza + Caja Fuerte.
3. **Conciliación TPV:** Comparativa automática entre lo contado y lo que reporta el sistema de ventas.
4. **Exportación Dual:** Reporte por WhatsApp y archivo JSON de auditoría profunda.
