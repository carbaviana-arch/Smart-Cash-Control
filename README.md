# Smart Cash Professional v2.2 🚀

Sistema avanzado de gestión de caja, arqueos físicos y conciliación de pagos electrónicos con interfaz nativa profesional.

## 🆕 Novedades en la v2.2
* **Interfaz Nativa Premium:** Rediseño completo con una paleta de colores sobria (Azul Corporativo y Gris Oxford) y tipografía *Inter* para una apariencia de app bancaria profesional.
* **Iconografía Vectorial:** Integración de *Lucide Icons* para una visualización nítida, moderna y ligera (sin uso de imágenes pesadas).
* **Módulo de Conciliación de Tarjetas:** Nueva sección dedicada para cruzar las ventas registradas en el TPV contra el cierre real del Datafono, calculando diferencias automáticamente.
* **Reporte de WhatsApp 2.0:** Formato optimizado que incluye la fecha automática, desglose detallado de flujos y estado visual (✅/❌) de la conciliación de tarjetas.

## 📊 Módulos Principales
1.  **Resumen Contable:** Control de flujo neto diario (Fondo Ayer, Ventas, Gastos y Sobres).
2.  **Arqueo de Efectivo:** Desglose pieza a pieza por denominación más el saldo de **Caja Fuerte**.
3.  **Conciliación TPV:** Comparativa automática entre el efectivo real contado y el teórico del sistema.
4.  **Conciliación Visa:** Verificación de cuadre de pagos electrónicos.
5.  **Historial Local:** Registro rápido de cierres anteriores para consulta inmediata.

## 🛠️ Especificaciones Técnicas
* **Tecnologías:** HTML5, CSS3 (Flexbox/Grid), JavaScript Vanilla.
* **Iconos:** Lucide Icons (vía CDN).
* **Persistencia:** LocalStorage para historial y cierres.
* **Portabilidad:** Formato JSON para auditorías externas.
