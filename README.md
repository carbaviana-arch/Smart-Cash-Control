# Smart Cash Control v2.0 - Pro Edition 🚀

Esta versión representa un salto cualitativo en la gestión financiera del negocio, integrando un módulo de contabilidad activa para el flujo de caja diario.

## 🆕 Novedades en la v2.0
* **Módulo "Resumen Cierre":** Nueva sección prioritaria para el control de flujo neto.
* **Cálculo de Fondo Hoy:** Implementación de la fórmula automática `Fondo Ayer + Efectivo - Gastos - Sobre`.
* **Desglose de Gastos:** Campo dedicado para detallar compras o pagos realizados desde caja, permitiendo una trazabilidad total.
* **Sincronización de Fondos:** El "Fondo Hoy" calculado se convierte automáticamente en la sugerencia para el día siguiente.

## 📊 Campos del Resumen
* **Fondo Ayer:** Base con la que se inició la jornada.
* **Visa:** Total cobrado por tarjeta.
* **Efectivo:** Dinero líquido ingresado.
* **Gastos:** Salidas de dinero para pagos a proveedores o compras menores.
* **Sobre:** Cantidad retirada de caja para depósito o reserva.
* **Fondo Hoy (Auto):** Resultado final que debe permanecer en el cajón.
