# Smart Cash Control - v1.1 Premium

Aplicación profesional de arqueo de caja con diseño inspirado en **iOS 18**. Optimizado para hostelería y retail que requieren un control estricto de caja y conciliación de tarjetas.

## ✨ Novedades Visuales (v1.1)
* **Dock Flotante:** Navegación minimalista con efecto Glassmorphism.
* **Cabecera Dark:** Contraste elegante con icono identificativo integrado.
* **Micro-interacciones:** Animaciones suaves al cambiar entre Caja e Historial.

## ⚙️ Funciones Core
1. **Sugerencia Automática:** Detecta el fondo de caja del día anterior para agilizar la entrada de datos.
2. **Conciliación Doble:** Valida descuadres tanto en efectivo como en pagos con tarjeta.
3. **WhatsApp Sync:** Exporta el resumen del día a un grupo de WhatsApp con un solo clic.
